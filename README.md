# Hichem — Portfolio

Personal portfolio site, served with GitHub Pages.

- Page: `site/index.html` (plain HTML/CSS, no build step)
- Deploy: `.github/workflows/pages.yml` publishes `site/` on every push to `main`

## Enable GitHub Pages
1. Make the repo public (or use a GitHub Pro/Team plan for private Pages).
2. Settings → Pages → Source: **GitHub Actions**.
3. Merge to `main` — the site goes live at https://hichemha.github.io/claude/
